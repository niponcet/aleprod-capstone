# Brand Assets — Alejandra Producciones (aleprod-capstone)

Esta carpeta es el **repositorio maestro de identidad visual y recursos de marca** del monorepo.

## Estructura de distribución automática hacia proyectos:

- **`mobile/assets/`**: Íconos de aplicación empaquetados para Expo / EAS Build (iOS y Android).
- **`mobile/public/`**: Íconos de instalación PWA (`apple-touch-icon.png`, `icon.png`, `favicon.png`).
- **`web/public/`**: Logos vectoriales y recursos estáticos para el Panel de Control Next.js 16.

Pega aquí tus archivos y carpetas de logos originales (SVG, PNG alta resolución, versiones horizontal, vertical, isotipo).
