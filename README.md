# Aleprod - Sistema de Gestión Operativa e Inventario 

**Proyecto Capstone (APT) - Duoc UC**  
*Ingeniería en Informática*

Este repositorio contiene la documentación y el código fuente (Fases posteriores) para el proyecto de modernización operativa desarrollado para **Alejandra Producciones**. 

La solución busca digitalizar y estandarizar el control de inventario y la trazabilidad técnica de las pistas de baile/pantallas LED utilizadas en eventos masivos, reemplazando los procesos manuales por una arquitectura moderna y offline-first.

## Objetivo del Proyecto
Diseñar, desarrollar e implementar un Producto Mínimo Viable (MVP) compuesto por:
1. **Aplicación Móvil en Terreno:** Orientada a los operarios, con capacidad de lectura de códigos QR para identificar palmetas LED, reportar fallas in situ, tomar evidencia fotográfica y funcionar sin conexión a internet (Offline-first mediante SQLite).
2. **Dashboard Administrativo Web:** Orientado a la jefatura de Aleprod para la gestión CRUD del inventario, monitoreo en tiempo real del estado de los equipos e historial de mantenciones.
